# まなびっこ｜iPhoneで使う手順

これは高校受験の社会学習とペット育成を組み合わせた、ホーム画面に追加できるWebアプリ（PWA）です。App Storeから入れる通常のiPhoneアプリではありませんが、Safariからホーム画面に追加してアプリのように起動できます。

## いちばん簡単な公開方法（GitHub Pages）
※ 初回のみ、GitHubアカウントとインターネット接続が必要です。

1. ZIPを展開します。
2. GitHubで新しいリポジトリを作成します（例：`manabikko`）。公開設定はPublicにします。個人情報は入れないでください。
3. 展開したフォルダ内の `index.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` をリポジトリの一番上にアップロードします。
4. リポジトリの **Settings → Pages** を開き、Build and deployment の Source を **Deploy from a branch**、Branch を **main**、フォルダを **/(root)** にして Save。
5. 公開が完了すると `https://あなたのユーザー名.github.io/manabikko/` のようなURLが表示されます。iPhoneのSafariで開きます。
6. Safariの共有ボタン → **ホーム画面に追加** → 必要なら「Webアプリとして開く」を有効にして「追加」を押します。
7. ホーム画面の「まなびっこ」アイコンから起動します。

## 入っている機能
- 地理・歴史・公民・総合の選択問題
- 正解で経験値、連続正解ボーナス、おやつ獲得
- ペットのレベルアップ・お世話・名前変更
- 間違えた問題の復習一覧
- 学習記録の端末内保存（ブラウザのデータを消すと記録も消えます）
- 一度読み込んだ画面を再表示するための簡易オフラインキャッシュ

## 注意
- このZIPをダウンロードしただけでは、ホーム画面に追加できる公開URLはまだありません。
- 学習記録はこの端末のブラウザ内に保存され、端末間同期はしません。
- 問題は学習用の試作問題です。実際の入試範囲に合わせて追加・確認してください。
- GitHub Pagesの公開URLはインターネット上で閲覧可能になります。個人情報は登録しないでください。
