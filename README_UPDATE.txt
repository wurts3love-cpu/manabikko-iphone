## GitHubで更新
1. ZIPを展開する。
2. GitHubの manabikko-iphone リポジトリで Add file → Upload files。
3. このフォルダのファイルをすべてアップロードして、同名ファイルを置き換える。
4. Commit changes。GitHub Pagesの反映を待つ。
5. iPhone Safariでサイトを開き、再読み込みする。古い表示が残る場合はSafariのタブを閉じて開き直す。

## 大事な点
現在の問題バンクは既存のサンプル問題を基にしたものです。約10,000問を中学1〜3年の全範囲で正確に揃えるには、教科書準拠の問題データを段階的に追加し、学年・単元・問題形式・解説を確認する必要があります。この更新で10,000問が完成したわけではありません。

セーブデータは利用中のブラウザ内に保存されます。個人情報は入力しないでください。
